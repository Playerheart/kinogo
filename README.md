# 🎬 Кино — личное iOS-приложение

Нативное приложение для просмотра `mix.kinogo.mu`. Каталог, поиск, выбор озвучки, плеер, скачивание — без рекламы сайта.

## Как это работает

1. **Парсер** (скрытый `WKWebView`) загружает страницы сайта и извлекает из них только данные: название, постер, описание, ссылки на плееры и скачивание.
2. **Нативный SwiftUI** рисует каталог и карточку фильма.
3. **Плеер** — отдельный `WKWebView`, который грузит только iframe видеохостинга. Всей обвязки с рекламой сайта там нет.

## Установка

1. Откройте вкладку **Actions** → **Build Unsigned IPA** → **Run workflow**.
2. Через 5–15 минут в README появится ссылка на `CinemaApp.ipa`.
3. Скачайте, подпишите на iPhone (TrollStore / ESign / Scarlet / SignTools), установите.

## Что можно подстроить

- **Селекторы парсера** — в `CinemaApp/ExtractionScripts.swift`. Если какие-то фильмы не появляются или не находятся плееры, там можно поправить регулярные выражения и селекторы.
- **Домены плееров** — в `CinemaApp/PlayerView.swift` есть список разрешённых хостов. Можно добавить новые.

## Ограничения

- Если сайт сильно меняет вёрстку, парсер может перестать находить данные. Тогда в карточке фильма появится кнопка «Открыть страницу фильма» — откроется в Safari.
- Плеер работает как есть: выбор качества и переключение серий — внутри iframe видеохостинга.
